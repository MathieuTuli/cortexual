# Cortexual

A brutalist/Y2K second brain webapp for storing notes, images, videos, and links.

## Getting Started

```bash
npm install
npm run dev
```

## Features

- **Cards**: Store notes, images, videos, and links
- **Spaces**: Organize cards into spaces
- **Tags**: Add tags to cards for filtering
- **Subnotes**: Add subnotes to any card
- **Search**: Search across all cards
- **Masonry Grid**: Responsive packed grid layout

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Zustand (state management)
- Dexie.js (IndexedDB)
- Radix UI (accessible primitives)
